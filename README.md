# Business Statistics & Economic Data Analysis Using Python

## Project Overview

This project focuses on analysing economic and logistics-related data across 148 countries using statistical methods and Python. Developed as part of my Business Statistics coursework, the project uses **AI-assisted coding (vibe coding)** to develop analytical workflows, perform statistical tests, visualise results, and interpret findings from a business perspective.

The primary objective is to examine the relationship between GDP per capita and logistics performance and identify meaningful patterns in the data.

## Objectives

- Analyse relationships between economic indicators and logistics performance.
- Apply statistical hypothesis testing to investigate research questions.
- Perform correlation and regression analysis to understand relationships between variables.
- Visualise data to identify trends, distributions, and differences across groups.
- Translate statistical results into meaningful business insights.

## Technologies & Tools Used

- **Python** – Statistical analysis and data processing
- **Google Colab** – Cloud-based development and execution
- **ChatGPT / AI-assisted coding** – Assistance with code generation, debugging, and analytical workflows
- **Pandas & NumPy** – Data manipulation and numerical operations
- **SciPy** – Statistical tests and hypothesis testing
- **Matplotlib & Seaborn** – Data visualisation

## Statistical Methods Implemented

The project applies the following techniques, as implemented in the notebook:

- Descriptive statistics and exploratory data analysis
- One-sample and independent-samples t-tests
- Chi-square test of independence
- One-way ANOVA
- Pearson correlation analysis
- Simple linear regression
- Mann–Whitney U test
- Kruskal–Wallis test
- Data visualisation using histograms, box plots, scatter plots, and bar charts

## Key Research Question

**Is GDP per capita associated with logistics performance across countries?**

The analysis examines the relationship between these variables using correlation and regression, supported by visualisations and additional statistical tests. Results are interpreted based on statistical evidence, while recognising that correlation does not establish causation.
